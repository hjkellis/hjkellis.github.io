# Intro
Connect 4 is a solved game, meaning for any given game position the solution can be computed given that both players are playing perfectly. In practice, it is nearly impossible for a human player to play the game perfectly. That is the purpose of this _Connect 4 Engine_, it uses traditional AI methods to solve the game.
